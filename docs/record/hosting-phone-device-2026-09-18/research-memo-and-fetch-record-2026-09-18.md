## Part C — INFERENCES (not vendor text), which the sheet marks as such

**The SWA fallback gap.**
- An unauthenticated deep link that matches no file may receive `index.html` without the `/*` check.
- The JavaScript files are real files, so they stay gated.
- Hence the sheet's named test.

**Cloudflare.**
- Restriction to one tenant likely comes from the tenant ID in the identity-provider config, plus an Emails policy.
- Access on a custom domain likely needs that domain's DNS on Cloudflare. **To confirm.**

**The gate protects static files only.** Calls to `*.supabase.co` and `graph.microsoft.com` go to other origins. Data security still rests on Supabase Auth and RLS.

**Redirect returns.**
- A Supabase or MSAL redirect back to the hosted origin passes the gate while the gate's own session is valid.
- If the gate's session has expired, its sign-in detour may drop a URL fragment or `?code=`. **Test it.**

**On the phone.** A magic link opens in Safari, not in the home-screen app. With PKCE, a flow started in the home-screen app would fail. That is the reason for the six-digit code.

**Which flow the app uses** (PKCE or implicit) is a `src/` fact, not read. It is a Code verification, not an assumption.
